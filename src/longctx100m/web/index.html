Single-request long-context inference

Bring the whole context.

텍스트 파일 전체와 질문을 한 요청으로 보냅니다. 입력을 검색 조각이나 다중 에이전트 요약으로 대체하지 않습니다. 서버는 전체 입력을 추론 백엔드에 전달하고, 백엔드가 1억 토큰 처리와 무절단을 명시적으로 지원할 때만 결과를 표시합니다.

업로드 후 서버가 모델의 실제 tokenizer로 입력 토큰 수와 백엔드 용량을 먼저 확인합니다. 1억 입력 목표나 출력 예산을 만족하지 않으면 추론을 시작하지 않습니다. 응답의 해시·처리 토큰 수·절단 여부도 검증합니다.

업로드는 서버 임시 파일로 스트리밍되며 추론 후 삭제됩니다. 최대 업로드 용량은 서비스 설정에 따릅니다.
